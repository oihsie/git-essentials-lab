# Run Guide

## Prerequisites
- Python 3.9 or later
- Git 2.23 or later
- JDK 17 or later

## Running the Demo 

Run the following command from the project root :

	python3 run.py demo

## What the Demo Does 
This command compiles the Java libarary code and runs a short demonstration of the library's
demonstration of the library's borrowing, return, and seartch features.
